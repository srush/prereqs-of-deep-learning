# Stylesheets

`tufte.css` comes from [DiffRast](https://github.com/srush/DiffRast/blob/main/docs/tufte.css),
retrieved September 10, 2026, with a provenance comment and absolute ET Book font URLs.
It derives from [Tufte CSS](https://github.com/edwardtufte/tufte-css) and
[ET Book](https://github.com/edwardtufte/et-book).

`verso-tufte.css` adapts the typography to Verso's interactive Lean code.
Run `make docs` after changing the stylesheets.
